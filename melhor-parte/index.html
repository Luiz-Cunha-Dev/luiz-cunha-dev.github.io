Melhor Parte

O Melhor Parte é o canal de cortes Melhor Parte Oficial no YouTube. O aplicativo Melhor Parte Youtube é uma ferramenta de uso pessoal, que roda no computador do próprio dono do canal, para publicar os cortes produzidos por ele no seu próprio canal do YouTube, usando a API oficial do YouTube (YouTube Data API v3).

O aplicativo não é oferecido ao público, não tem cadastro e não acessa contas de outras pessoas.
