Política de Privacidade

Última atualização: 20 de outubro de 2026.

Esta política descreve como o aplicativo Melhor Parte Youtube (“o aplicativo”) trata os dados obtidos das contas Google/YouTube que o autorizam.

Quem usa

O aplicativo é de uso pessoal do dono do canal Melhor Parte Oficial e roda apenas no computador dele. Não há outros usuários.

Que dados acessa

  • Permissão para enviar vídeos ao canal do YouTube autorizado (escopo youtube.upload).
  • Leitura do nome e identificador do canal autorizado (escopo youtube.readonly), só para mostrar qual canal está conectado.

Como usa

Os dados são usados exclusivamente para publicar, no próprio canal, os vídeos escolhidos pelo dono do canal, e para mostrar no aplicativo qual canal está conectado. O aplicativo não lê, não altera e não apaga outros vídeos, comentários ou dados da conta.

Onde fica guardado

O token de acesso concedido pelo Google fica salvo somente no computador do dono do canal. Nenhum dado é enviado para servidores do aplicativo (o aplicativo não tem servidores), vendido, compartilhado com terceiros ou usado para publicidade.

Uso limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O aplicativo também segue os Termos de Serviço do YouTube.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions ou desconectando o YouTube dentro do aplicativo, o que apaga o token salvo no computador.
